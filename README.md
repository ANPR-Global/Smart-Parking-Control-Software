Smart Parking Control SoftwareA high-performance, hybrid Automatic Number Plate Recognition (ANPR) system that combines local, low-latency vehicle detection (Python & C++) with high-accuracy cloud OCR pipelines. It is engineered for automated parking barriers, toll gates, and compound surveillance systems.   The system includes a web dashboard accessible anywhere from any browser, allowing operators to trigger gates, manage parking access, whitelist vehicles and tenants, and monitor real-time logs and analytics.   🛠️ System Architecture & How It WorksLocal Detection (Edge): Local C++ executable instances process high-speed RTSP streams to detect vehicles entering a Region of Interest (ROI).   Cropping & Cloud Verification: The cropped plate frame is sent to cloud OCR servers.   Gate Actuation: If authorized, the system sends an execution command via TCP/IP to actuate the barrier.   Cloud Analytics & Storage: Scans, timestamps, and cropped image logs are saved for viewing via the web interface.   🚀 Setup & Setup GuidePhase 1: Local Application DeploymentStepTaskDetails1.1Download Source FilesClone or download the repository to your local computer.   1.2Build C++ BinariesCompile the C++ core files using your C++ environment to generate the 2 required executables.   1.3Launch GUIRun Local_APP_qt.py using Python 3.   1.4Automatic ExecutionThe app automatically launches the compiled C++ workers.
